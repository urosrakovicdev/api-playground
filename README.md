# API Playground

A React-based tool for composing and sending HTTP requests with a visual pipeline, built with Vite, TypeScript, and Tailwind CSS.

## Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/urosrakovicdev/api-playground.git
   cd api-playground
   ```

2. **Install dependencies**

   ```bash
   pnpm install
   ```

3. **Start the development server**

   ```bash
   pnpm dev
   ```

   The app will be available at `http://localhost:5173`.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
